# 参考图片目录

本目录存放桌宠设计参考图片。

## 图片命名规范

| 文件名 | 用途 | 说明 |
|--------|------|------|
| `ink-sphere-v1.png` | 设计参考 v1 | 带棋盘格背景版本 |
| `ink-sphere-v2.png` | 设计参考 v2 | 透明背景 PNG 版本 |
| `ink-sphere-*.png` | 其他变体 | 不同旋转角度/情绪状态的变体 |

## 设计要点回顾

- **核心**：墨滴球，内部太极 S 线流动，外部罗夏墨迹变化
- **眼睛**：两个纯白圆孔，位置即太极阴阳点
- **动画**：自转 + 墨流动 + 墨丝螺旋扩散 + 情绪变化
- **配色**：黑白灰水墨风，透明背景
- **感觉**：太极但不刻板，像罗夏墨迹但有确定性骨架
