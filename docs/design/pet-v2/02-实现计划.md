## 架构决策

### 渲染方案：Three.js / React Three Fiber + GLSL Shader

| 方案 | 判定 |
|------|:--:|
| Canvas 2D | ❌ 放弃 — 质感（光照/法线/折射）难以在 Canvas 2D 中实现 |
| WebGL/Three.js | ✅ 当前方案 — 自定义 GLSL ShaderMaterial 实现水墨质感 |

**决策变更 (2026-06-17)**：Canvas 2D 在光泽/法线/液体感方面存在天然限制。已于 P4 完成 Three.js 迁移，使用自定义 GLSL vertex/fragment shader 实现：
- 多频异步液体呼吸形变
- 表面张力波纹（顶点位移）
- 有限差分法线修正（高光随形变流动）
- Chromatic Fresnel 边缘光

### 窗口规格

```
当前: 200×200px → 球半径 76px
目标: 350×350px → 球半径 133px + 墨丝外扩 50-80px
```

## 渲染管线（每帧执行顺序）

```
1. clearRect()                              // 清空
2. 隔离白底 rgba(255,255,255,0.025)          // 防壁纸渗透
3. drawBubbles()          — P5-1             // 背景气泡（最底层）
4. drawFarTrails()        — P1（远层）       // 远距离墨丝
5. drawInkSplatters()     — P5-2             // 墨滴飞溅
6. drawSphereBody()       — P4-1, P4-2, P4-4 // 球体基础光
7. drawInternalInk()      — P2, P3           // 内部墨流 + 罗夏变化
8. drawNearTrails()       — P1（近层）       // 近距离墨丝
9. drawEyes()             — 现有              // 白色圆孔眼睛
10. drawSpecularHighlight() — P4-3           // 镜面高光（最顶层）
```

## 已知风险与待优化项 (2026-06-17 23:30)

当前 P4 顶点级表面形变方案在预览阶段工作良好，但识别到以下三项风险，
需要在进入桌宠模式前逐项解决。**原则**：先保留当前效果不动，等后续 P1/P2 接入时统一调整。

### 风险 1：纹理皱纹感（拟人化老化）

| 属性 | 说明 |
|------|------|
| **严重度** | 🔴 设计问题 |
| **现象** | 3 层正弦波均匀覆盖球体全表面 + 持续振荡 → 密布小凸起 → 视觉上类似皮肤皱纹/老化 |
| **根因** | 形变覆盖率 100%（每顶点每帧都在进出）+ wave3 空间频率 6~8 周期/球面 + 2.6Hz 高频 |
| **与液体感的差异** | 真实水面波纹是**局部、瞬态**的（某处鼓起时别处已平）；皱纹是**静止、遍布**的 |
| **解决方向** | ① 形变覆盖率从 100% 降至 20~30%（仅球体局部区域）② 给形变加"发生→消退"生命周期而非持续振荡 ③ 降 wave2/wave3 幅度至 0.2~0.3× |

### 风险 2：表情识别干扰

| 属性 | 说明 |
|------|------|
| **严重度** | 🔴 架构问题 |
| **现象** | 未来叠加眼睛后，shader 顶点位移会让眼睛位置不可预测微移、圆形变椭圆、眨眼逻辑无法叠加 |
| **根因** | 形变作用在**底层几何**（vertex shader 位移 position），面部区域没有做区域排斥 |
| **桌宠特殊性** | 桌面宠不同于游戏奇幻生物——用户需要**稳定识别表情**，眼神飘忽会破坏情感传达 |
| **解决方向** | ① 基础球体保持静止或仅极慢宏观呼吸 ② 液体感迁移至**叠加的粒子/纹理层**，不干扰面部 ③ 或 vertex shader 中对面部区域（眼睛附近 ±15°）做形变遮蔽 |

### 风险 3：累计性能瓶颈

| 属性 | 说明 |
|------|------|
| **严重度** | 🟡 当前 OK，未来风险 |
| **当前开销** | SphereGeometry(64,64) ≈ 4097 顶点，每帧 ~12291 次 `computeDisplacement` 调用（每顶点 3 次有限差分采样），~98328 次三角函数 |
| **当前状态** | 350×350 WebGL 窗口可稳定 60fps |
| **叠加压力** | P1 墨丝粒子 10-20 条 Bézier；P2 内部墨流 3-5 metaball 逐像素 fragment shader；P5 气泡 5-15 个半透明粒子 |
| **叠加后预估** | vertex shader 12000 次位移计算 + 粒子模拟 + metaball fragment → 可能跌破 45fps 阈值 |
| **解决方向** | ① 几何体降采样（64→48 仍够用）② vertex shader 去有限差分，改用解析梯度或干脆低频法线近似 ③ 整体降频至桌宠节奏后开销自然降低 |

### 降频到桌宠节奏的参考方向

> 以下数值仅为讨论参考，尚未实施。

| 参数 | 预览模式（当前） | 桌宠模式（目标感） |
|------|:--:|:--:|
| Y 轴呼吸周期 | ~5.7s (1.10Hz) | ~12-15s (0.4-0.5Hz，匹配真实呼吸) |
| wave3 高频涟漪 | 2.6Hz, 幅度 0.007-0.009 | 0.3× 幅度或关闭 |
| 形变覆盖率 | 100% | 20-30%（仅球体底部局部） |
| wave1/wave2 幅度 | 30/20 | 10/7（按比例缩至 0.3×） |
