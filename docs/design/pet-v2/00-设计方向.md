# 桌宠 V2 设计方向 —— 水墨风

> 最后更新: 2026-06-17 23:20 — P4 Three.js 引擎完成：异步多轴呼吸 + 顶点级表面形变 + 有限差分法线修正

## 设计主题

**一枚悬浮在清水中的墨滴球**，缓慢地旋转、流动、呼吸。

```
        ╱╲────╱╲
       ╱  ●  ●  ╲   ← 白色圆孔眼睛
      │  浓墨偏左上  │  ← 墨色内部不均匀
       ╲  淡墨下半部分 ╱
        ╲╱────╲╱
       ╲ ↙     ↘╱    ← 极细墨丝旋转扩散
        旋转方向的墨迹
```

## 核心视觉元素

| 元素 | 描述 | 实现要点 |
|------|------|----------|
| **球形主体** | 完美正圆形的墨滴球体，无尖端，无泪滴形 | 纯球形，边缘柔和 |
| **内部浓墨** | 球内左上区域有一大块偏浓的实心黑墨，像重心偏移的重液 | 墨色不均匀，有"晃动/沉淀"感 |
| **淡墨过渡** | 其余部分为半透明的浅灰色水墨渐变 | 有墨色晕染层次 |
| **白色圆孔眼睛** | 两个干净的圆形白色空洞（无墨），露出背景 | 位置居中偏下，尺寸约为球直径的 15-20% |
| **旋转墨丝** | 从球体表面向四周散发极细的墨丝，随旋转方向呈螺旋状向外扩散 | 发丝般纤细、优雅、流动 |
| **消散尾迹** | 墨丝在水中逐渐变淡、消散，像烟雾或丝绸 | 自然消散曲线 |
| **悬浮气泡** | 背景有极细小的空气泡泡点缀 | 增强"在水中"的感觉 |

## 动态效果（关键）

### 核心运动逻辑：太极为骨，罗夏为形

**设计哲学**：以**太极**图案为核心运动骨架，以**罗夏墨迹**为表现形态。

```
太极核心（基础图形）：
  ╱╲     ← 阴阳两仪，S 形分割
 ╱██╲
╱██╲ ╲
 ╲██╱╱
  ╲╱     ← 对称但不刻板

罗夏变化（动态变化）：
  ╱~~↩  墨色沿 S 线不断生长、断裂、重组
  ╲__↪  墨丝从球表面渗散
```

**动态墨变化三原则：**

| 维度 | 描述 |
|------|------|
| **确定性** | 墨色的核心运动沿太极 S 曲线分布——永远围绕阴阳两仪的内在张力 |
| **随机性** | 墨丝的具体形态、扩散方向、消散速度带有随机扰动——像罗夏墨迹一样每次不同 |
| **非随机** | 不同情绪状态对墨色有明确导向——专注时墨色向核心凝聚，卡文时墨色向边缘涣散 |

### 太极核心运动

- **太极 S 线**：内部浓墨的基础分布沿太极 S 线缓慢流动，像液体在球体内循环
- **阴阳眼**：两个圆孔眼睛即太极的阴阳点位置——固定位置但随墨流有轻微偏移
- **S 形流动**：浓墨沿 S 线做周期运动，周期约 8-12 秒

### 罗夏墨迹变化层

- **墨迹生长**：墨色边缘不断生成新的细小墨迹，又不断消散
- **墨迹断裂**：墨丝不断从主体断裂、扩散，像墨迹在水中散开
- **永远不对称**：墨色永远不会形成完美对称的太极图——永远"像罗夏墨迹"
- **呼吸式扩散**：墨色有缓慢的扩散-凝聚循环

### 情绪 ↔ 墨迹形态映射

| 状态 | 墨色表现 | 罗夏感 |
|------|----------|--------|
| **空闲** | 沿 S 线缓慢流动，墨丝少量扩散 | 柔和、平衡 |
| **专注** | 浓墨向核心凝聚，墨丝变密集 | 锐利、有向性 |
| **卡文** | 墨色向边缘涣散，墨丝变稀薄 | 模糊、混乱 |
| **成就** | 墨色爆发式扩散，随后重新凝聚 | 激烈、有序 |
| **休息** | 墨色整体变淡，接近消散 | 平静、极简 |

### 旋转与呼吸

- **缓慢自转**：球体以恒定缓慢速度旋转（约 3-6 秒 / 圈）
- **墨流独立运动**：球内浓墨沿太极核心流动，与球体自转方向/速度不完全一致——产生"相对流动"感
- **墨丝螺旋扩散**：墨丝沿旋转方向甩出，弧线优美
- **墨色呼吸**：整体墨色有极轻微的明暗呼吸（±5-10% 亮度变化）

### 情绪状态

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| **空闲** | 太极 S 线缓慢流动 + 墨丝少量扩散 | 用户无操作时 |
| **专注** | 墨色向核心凝聚 + 墨丝增多 + 墨色加深 | 用户打字/写作时 |
| **卡文** | 墨色向边缘涣散 + 墨丝变稀薄 + 眼睛颤动 | 长时间无输入 + 频繁删除 |
| **成就** | 墨色爆发扩散 → 沿 S 线重组 | 完成章节/达成目标 |
| **休息** | 墨色整体变淡 + 接近消散 | 用户长时间离开 |

### 交互反馈

- **鼠标悬停**：球体微放大（105-110%），墨丝暂时加速向外
- **鼠标点击**：球体轻微"晃动"，内部浓墨偏移 + 产生新墨丝
- **拖拽移动**：球体有轻微倾斜，墨丝向移动反方向拉伸

## 实现路径

### ✅ V2.0 —— 基础形态（已完成 P0~P4）

1. **Three.js / React Three Fiber 引擎**：自定义 GLSL ShaderMaterial 实现水墨球体渲染
2. **光照系统**：ambient + diffuse + specular + Fresnel rim light + 背光透射
3. **墨色密度场**：基于法线点积的非均匀墨色分布（左上浓墨 → 右下淡墨）
4. **液体呼吸动画**：异步多轴缩放 + 顶点级表面形变 + 有限差分法线修正
5. **独立预览**：`npm run dev:preview` 纯 Vite 启动，无需 Electron

### ⬜ V2.1 —— 流体动画（竞进）

1. **内部墨流**：multi-blob 耦合振荡器 + metaball 渲染（P2）
2. **罗夏墨迹变化**：墨团边缘不规则 + 断裂/重组 + 呼吸式扩散循环（P3）
3. **墨丝粒子系统**：从球面切线方向发射螺旋墨丝（P1 已在 Canvas 2D 完成，需迁移至 Three.js）

### ⬜ V2.2 —— 智能响应

1. **心流状态联动**：与现有 flowMonitor 数据流对接
2. **多状态切换**：根据用户行为自动切换动画模式
3. **对话展开 UI**：墨丝向右侧延伸展开对话面板
