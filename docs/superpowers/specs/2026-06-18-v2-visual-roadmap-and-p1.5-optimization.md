### 1.4 设计理念：墨色生物

球体本身是**带一点点淡墨色的清澈水球**，内部的"墨"是活的——汇聚成一个浓墨核心团漂浮在水球中，外部仅剩余极淡的墨色晕染和墨团飘过后留下的墨迹。后续阶段的墨迹、墨团叠加在这个清澈基态上，层次分明。

**渲染层级模型（从下到上）：**

```
第 1 层：背景底色
第 2 层：球体背面（Shader 基色 + 背光透射）
第 3 层：墨团 + 墨迹（球体内部）  ← InkBlob + InkTrail
第 4 层：球体外侧 Shader（高光 + Fresnel）
第 5 层：外部墨迹（球面 FBM 噪声斑块）  ← P2 已完成外部墨斑
第 6 层：双眼（球体内表面）
```

## 三、P3 墨团（✅ 已完成）

### 3.1 实现方案

**文件：** [InkBlob.tsx](file:///d:/Projects/ai-writing-coach/desktop-pet/src/renderer/components/pet-v2/InkBlob.tsx)

**架构：** 自定义 `ShaderMaterial`（无 FBM 噪声、无有机变形），纯几何球体 + 和外部球体完全一致的光照模型。

**光照参数**：与 `waterSphereMaterial.ts` 的 9 个 uniform 值完全一致。

**呼吸形变**：采用与水球相同架构的 `computeDisplacement` 方法，但波形参数不同（横向旋转涟漪 + 斜向波动 + 中频涟漪），频率/方向/振幅均有区别，避免和水球"同步"呼吸。

**动画**：正弦波漂浮在左上方（x±0.08, y±0.06, z±0.07），默认中心 `(-0.15, 0.2, 0.08)`。

**大小**：`baseScale = 0.15 + blobSize × 0.5`，默认 `blobSize=0.72` → 占球体半径约 35%，滑块 0.05~1 可调。

**控制面板**：
- `墨团大小`：0.05~1，默认 0.72
- `墨团浓度`：0.1~1，默认 0.8

### 3.2 排坑记录

**排坑 #1：ShaderMaterial 静默失败**
- 现象：多次迭代后墨团突然消失，颜色、大小均不可见
- 根因：`WaterSphere.tsx` 向 `InkBlob` 传 props 但 InkBlob 接口已变更 → TypeScript 编译错误 → Vite HMR 静默失败 → 浏览器跑旧代码
- 修复：保持接口一致，每次修改后 `npm run typecheck`
- 教训：HMR 失败不会报错，修改后务必验证 typecheck

**排坑 #2：Shader 中 alpha 计算导致透明**
- 现象：添加光照后墨团消失，但红色 `meshBasicMaterial` 能显示
- 根因：`diffuse = 0.06 + NdotL * 0.1` 底值太低，`(0.028*0.06, 0.05*0.06, 0.078*0.06)` 接近纯黑
- 修复：统一使用水球的 diffuse 参数 `0.08 + NdotL * 0.78`

**排坑 #3：quaternion 赋值导致消失**
- 现象：设置 `meshRef.current.quaternion` 后墨团消失
- 暂未深入排查，改为 vertex shader 内实现变形方向
